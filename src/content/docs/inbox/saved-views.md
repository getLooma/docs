---
title: Save inbox views
description: Save the inbox's current filters as a named view in the sidebar, for yourself or, as an admin, for the whole organization, with a live count.
---

A saved view is a set of inbox filters with a name. Save the filters you use often, and open
them again from the sidebar under **Inbox**, where each view shows how many conversations match
it. Any member saves views for themselves; admins can also share a view with the whole
organization.

## Before you start

- Each member can have up to 10 personal views.
- An organization can have up to 15 shared views. Only admins create, change and delete them.

## Save a view

1. In the inbox, set the [filters](../filter-the-inbox/) you want.
2. Click **Save view**.
3. Enter a **Name** of up to 60 characters. As an admin, check **Share with the organization** to
   make the view shared.
4. Click **Save view**. The view appears in the sidebar under **Inbox**.

Once you have a view, **New view** in the sidebar opens the same dialog for the inbox's current
filters.

## Open a view

Click the view in the sidebar. The inbox loads its filters and shows the view's name as the page
title. Shared views come first and carry a people icon.

The count next to each view refreshes every minute. Above 999 it shows "999+".

In a shared view that filters on **Me**, each member sees the conversations assigned to
themselves.

## Change or delete a view

When you change a filter in an open view, the view is marked **Edited**.

- Click **Save changes** to update the view. Only admins can change a shared view.
- Click **Save as new view** to keep the original and save the new filters under another name.
- Click **Delete view**, then confirm, to remove the view from the sidebar. Conversations aren't
  changed.

If a tag that a view filters by is deleted, the tag is removed from the view's filters.
