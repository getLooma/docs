title: Set a conversation's status, assignee and priority
description: Any member changes a conversation's status, assignee and priority from the selects at the top of the conversation page.
---

Any member sets a conversation's **Status**, **Assignee** and **Priority** from the selects at
the top of the conversation page. A change is saved as soon as you choose a value, and the inbox
filters use the new value.

## Change the status, assignee or priority

1. Open the conversation.
2. Choose a value in **Status**, **Assignee** or **Priority**.

| Select       | Values                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------ |
| **Status**   | **Open**, **Pending**, **Resolved** or **Closed**                                                            |
| **Assignee** | **Unassigned**, or any member of your organization; you appear as **Me**, with your name in brackets         |
| **Priority** | **None**, or a number from **1 (most urgent)** to **25**; a lower number is more urgent than a higher number |

If Looma can't save a change, the select keeps its previous value and says so next to it, for
example "Could not change the priority."

## What the status changes

The reply box is shown only while a conversation is **Open** or **Pending**. To reply to a
**Resolved** or **Closed** conversation, set it back to **Open** first.

## Undo a macro's actions

A [macro](../macros/#apply-a-macros-actions) can set the status, the priority and the assignee
when you send a reply with it. To undo one of those changes, choose the previous value in these
selects.
