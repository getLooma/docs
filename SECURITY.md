# Security

## Reporting a problem

Please don't open a public issue. Report privately through GitHub's
[private vulnerability reporting](https://github.com/getLooma/docs/security/advisories/new), or
email `<security contact: to confirm>`.

Report anything sensitive you find in these docs or in this repository's history. That
includes a secret, an internal address, personal data, or a security problem with the
docs.getlooma.io site.

For a security problem with the Looma product itself, use the same channels; we route it to the
right team.

## Scope

This repository covers the documentation site and its content. Expect an acknowledgement within
three working days.
